## 📞 SUPORTE & DÚVIDAS

**Se algo não funcionar:**

1. PowerPoint não abre?
   → Instale Office 365 ou use LibreOffice Impress (grátis)

2. Fonte Segoe UI não aparece?
   → Download em: `fonts.google.com/specimen/Segoe+UI` ou use Arial como fallback

3. Cores não aparecem corretas?
   → Verifique modo de exibição (RGB vs CMYK) e projetor calibração

4. Timing muito rápido/lento?
   → Ajuste velocidade da fala. Scripts estão para velocidade normal (140 wpm)

5. Precisa de versão em PDF?
   → Abrir PowerPoint → File → Export as PDF
