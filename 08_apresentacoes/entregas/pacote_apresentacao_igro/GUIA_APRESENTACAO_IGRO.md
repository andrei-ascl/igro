# GUIA DE APRESENTAÇÃO DO IGRO PARA ALTA GESTÃO
**Recomendações de Comunicação Institucional**

---

## 1. ESTRUTURA DE APRESENTAÇÃO RECOMENDADA

### 1.1 Formato (10-15 minutos)

```
⏱️ 0-2 min    → Contexto e problema (por que existe?)
⏱️ 2-4 min    → Solução: o que é o IGRO (visão conceitual)
⏱️ 4-7 min    → Resultados principais (dados e achados críticos)
⏱️ 7-10 min   → O que fazer agora (aplicações e próximos passos)
⏱️ 10-15 min  → Perguntas e discussão
```

### 1.2 Materiais Visuais Mínimos

**Slide 1 — Problema**
- Imagem/ícone de: "múltiplos dados fragmentados"
- Frase-chave: "109 mil manifestações. Como transformá-las em decisão?"

**Slide 2 — Solução Visual**
```
MANIFESTAÇÃO CIDADÃ
       ↓
    [IGRO]  ← 5 indicadores integrados
       ↓
DECISÃO ESTRATÉGICA
```

**Slide 3 — Resultado Principal (Gráfico)**
- Grande: **IGRO = 52,9%** (com escala de cores: vermelho = crítico)
- Pequeno: Distribuição dos órgãos por faixa de risco (gráfico de barras empilhadas)

**Slide 4 — Achados (Infográfico)**
- 5 fatores de sucesso (ícones + texto curto)
- Exemplo de órgão de excelência vs. crítico (comparação lado a lado)

**Slide 5 — Próximos Passos (Timeline)**
```
AGORA           3-6 meses         6-12 meses
├─ Validar      ├─ Implementar    ├─ Evoluir
└─ Comunicar    └─ Capacitar      └─ Aperfeiçoar
```

## 2. LINGUAGEM RECOMENDADA

### O que EVITAR
❌ "Agregação por média geométrica ponderada"  
❌ "ISO 31000:2018 e COSO"  
❌ Jargão estatístico sem contexto  
❌ Listas longas de dados técnicos

### O que PRIORIZAR
✅ "Um único número que diz o essencial"  
✅ "Baseado em padrões internacionais confiáveis"  
✅ "Pronto para usar hoje"  
✅ "Identifica onde agir primeiro"

### Frases-Chave para Usar

| Contexto | Frase |
|---|---|
| **Abrindo** | "Temos dados valiosos sobre o Estado — falta transformá-los em decisão." |
| **Explicando IGRO** | "É um 'termômetro' que resume 5 sinais críticos em uma métrica única." |
| **Apresentando resultado crítico** | "39% da rede está em nível crítico — justamente onde há mais interação com cidadão." |
| **Explicando heterogeneidade** | "Não é tamanho que determina sucesso — é como gerencia." |
| **Encerrando** | "Essa metodologia permite priorizar recursos e visibilizar progresso." |

## 3. PRINCÍPIOS DE COMUNICAÇÃO NÃO VIOLENTA

Adaptando o conceito de CNV para contexto institucional:

### 3.1 Observação (Fatos, não julgamentos)
**✅ Correto:**  
"109.338 manifestações foram registradas em 2024-2025. 39% dos órgãos apresentam IGRO abaixo de 50."

**❌ Evitar:**  
"Muitos órgãos estão falhando miseravelmente."

### 3.2 Sentimentos/Contexto
**✅ Correto:**  
"Essa heterogeneidade oferece oportunidade: sabemos onde agir e como replicar boas práticas."

**❌ Evitar:**  
"A situação é desesperadora."

### 3.3 Necessidades Institucionais
**✅ Correto:**  
"Para fortalecer a confiança institucional, precisamos de velocidade E qualidade — não apenas uma."

**❌ Evitar:**  
"A ouvidoria não está funcionando."

### 3.4 Pedido (Ação clara)
**✅ Correto:**  
"Solicitamos aprovação para (1) validar metodologia com gestores, (2) implementar dashboard em X dias."

**❌ Evitar:**  
"Você deveria aceitar essa proposta."

## 4. ANTECIPANDO PERGUNTAS DA ALTA GESTÃO

### P1: "Por que esse índice é melhor que o que temos?"

**Resposta estruturada:**
- Indicadores isolados geram sinais conflitantes
- Lei de Goodhart: otimizar uma métrica distorce o resultado
- Exemplo prático: "Um órgão pode responder rápido mas ineficaz"
- Solução: índice composto força equilíbrio

### P2: "Quanto custa implementar?"

**Resposta estruturada:**
- Usa dados já existentes (SGOe)
- Implementação técnica: dashboard (X horas de desenvolvimento)
- Comunicação e capacitação: X dias
- Custo recorrente: manutenção mensal (X horas)
- ROI: decisões mais informadas reduzem retrabalho

### P3: "Como explicamos isso para os órgãos?"

**Resposta estruturada:**
- Não é "ranking de punição", é "mapa de prioridades"
- Órgãos com melhor desempenho podem ser mentores
- Metodologia é transparente e replicável
- Sucesso coletivo = melhoria da imagem pública estadual

### P4: "E se o órgão discordar do resultado?"

**Resposta estruturada:**
- Metodologia foi testada com análise de sensibilidade
- Índice é robusto a variações de ponderação
- Convida-se ao diálogo: "Que dados adicionais deveríamos considerar?"
- Transparência gera confiança

### P5: "Quanto tempo até ver resultado?"

**Resposta estruturada:**
- Curto (0-3 meses): visibilidade dos problemas, comunicação
- Médio (3-6 meses): implementação de ações, primeiro progresso
- Longo (6-12 meses): maturidade, consolidação de ganhos
- Métrica: acompanhamento trimestral do índice

## 5. STORYTELLING COM DADOS

### Estrutura Narrativa Recomendada

**Abertura (Incômodo/Tensão)**
"Recebemos mais de 100 mil manifestações por ano. Cada uma é um sinal de algo que precisa melhorar. O desafio: como transformar esses sinais em decisão estratégica?"

**Nó (Complicação)**
"Temos 5 métricas diferentes (tempo, satisfação, reabertura...). Conflitam entre si. Um órgão pode ser rápido mas ineficaz. Qual é a prioridade real?"

**Solução (Resolução)**
"Criamos um único indicador que obriga equilíbrio: IGRO. Sintetiza os 5 sinais de forma inteligente."

**Evidência (Dados)**
"Resultado: 52,9% crítico. Órgãos variando de 30% a 100%. Padrão claro: sucesso vem de gestão estruturada, não tamanho."

**Fechamento (Ação)**
"Proposta: usar esse indicador para (1) monitorar continuamente, (2) replicar boas práticas, (3) alocar recursos inteligentemente."

## 6. TRATAMENTO DE OBJEÇÕES

| Objeção | Resposta |
|---|---|
| "Índices compostos são complexos" | "A metodologia é complexa, mas o resultado é simples: um número entre 0 e 100." |
| "Isso vai aumentar pressão nos órgãos" | "Ao contrário — identifica onde ajudar e oferece modelo de sucesso." |
| "Qual é a validade estatística?" | "Testada com bootstrap, análise de sensibilidade, comparação de métodos. Robusto." |
| "Esse é mais um número" | "Não — é o único número que importa para decisão neste domínio." |
| "Por que não usar IEGM ou IFDM?" | "Esses não capturam especificidade de ouvidoria: percepção cidadã em tempo real." |

## 7. ROTEIROS POR AUDIÊNCIA

### Para Presidente/Governador (5 minutos)
1. "Temos invisibilidade estratégica sobre 100 mil manifestações"
2. "Criamos indicador que sintetiza a situação em um número"
3. "Resultado: 39% crítico. Oportunidade clara de melhoria."
4. "Proposta: acompanhar mensalmente e priorizar recursos"
5. "Benefício: melhor imagem pública + decisões mais informadas"

### Para Secretários/Órgãos (15 minutos)
1. Explicar contexto de heterogeneidade
2. Apresentar 5 fatores de sucesso (pode ajudá-los diretamente)
3. Mostrar casos de sucesso e críticos (learning)
4. Discutir plano de implementação participativa
5. Validar processo com feedback local

### Para Auditores/Compliance (30 minutos)
1. Referencial metodológico completo
2. Análise de sensibilidade (robustez)
3. Alinhamento com ISO 31000, COSO
4. Governança dos dados (SGOe como fonte)
5. Integração com Matriz de Gestão de Riscos

## 8. CHECKLIST PRÉ-APRESENTAÇÃO

- [ ] Garantir acesso ao painel/dashboard do IGRO antes de apresentar
- [ ] Validar números com gestor responsável pela área
- [ ] Preparar 2-3 exemplos concretos (órgãos específicos)
- [ ] Ter dados brutos à mão para responder a perguntas técnicas
- [ ] Enviar resumo executivo 24-48h antes (para leitura prévia)
- [ ] Conferir qualidade de imagens/gráficos em tela de projeção
- [ ] Preparar versão impressa do resumo para participantes
- [ ] Definir quem responde perguntas técnicas vs. estratégicas
- [ ] Agendar follow-up para decisão (não ficar em aberto)

---

## 9. APÓS A APRESENTAÇÃO

### Comunicado Interno (para órgãos)
- Explicar o IGRO com linguagem acessível
- Enfatizar aspecto de "apoio" e não "fiscalização"
- Disponibilizar dashboard e guia de interpretação
- Oferecer capacitação local

### Comunicação Pública (opcional)
- Publicar resumo em portal de dados abertos (transparência)
- Destacar órgãos de excelência (reconhecimento)
- Demonstrar compromisso com melhoria contínua
