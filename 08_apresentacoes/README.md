# Apresentações — IGRO

Slides, roteiros, scripts de apresentação e pacotes de entrega para comunicação dos resultados do IGRO.

## Estrutura

### `roteiros/`
Documentação de suporte para apresentações:
- `roteiro_apresentacao.md` — Outline estruturado com timing, falando-pontos e transições

### `entregas/`
Pacotes prontos para apresentação:
- `pacote_apresentacao_igro/` — Pacote de entrega completo:
  - `APRESENTACAO_IGRO_CGE-GO.pptx` — Versão v1
  - `APRESENTACAO_IGRO_v2.pptx` — Versão v2 (recomendada)
  - `RESUMO_EXECUTIVO_IGRO.md` — Sumário para leitura rápida
  - `GUIA_APRESENTACAO_IGRO.md` — Guia de contexto
  - `NOTAS_APRESENTADOR_IGRO.md` — Notes para presenter
  - `apresentacao_igro.html` — Versão interativa (fallback)
  - `ENTREGA_FINAL.md` e `ENTREGA_V2.md` — Registros de entrega

## Objetivo

Oferecer material estruturado para comunicação dos resultados do IGRO a stakeholders: gestores públicos, equipes técnicas, auditores e audiências executivas. Integra visualizações, narrativa e fundamentos metodológicos.

## Usando as Apresentações

1. **Apresentação rápida (~15 min):** Use `RESUMO_EXECUTIVO_IGRO.md`
2. **Apresentação completa (~45 min):** Use `APRESENTACAO_IGRO_v2.pptx` com `NOTAS_APRESENTADOR_IGRO.md`
3. **Contexto técnico:** `GUIA_APRESENTACAO_IGRO.md`
4. **Preparação:** `roteiros/roteiro_apresentacao.md`

## Scripts Relacionados

Scripts de geração e atualização estão em `05_scripts/python/apresentacoes/`.
